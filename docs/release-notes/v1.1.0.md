# 雾锁存档助手 1.1.0 / Enshrouded Save Vault 1.1.0

[中文](#中文) | [English](#english)

## 中文

**支持游戏 1.0 的新存档格式。** 雾锁王国 1.0 把每个世界改成了一个 `worldN.ksd` 文件，编号在每台电脑上可能不同；旧存档会被游戏自动转换，原文件移到 `migrated/`。工具 1.0.0 只认识抢先体验版的 8 位标识，无法管理新存档，1.1.0 起两种格式都支持。

### 下载哪个文件

| 文件 | 给谁用 |
| --- | --- |
| `EnshroudedSaveManager-1.1.0-win-x64.exe` | 每位玩家（Windows 10/11 x64），双击即用，无需安装 |
| `save-server-1.1.0-linux-amd64` / `-linux-arm64` | 服务器管理员，按服务器架构选择 |
| `SHA256SUMS.txt` | 下载后核对文件完整性 |

### 新内容

- **游戏 1.0 世界**：服务器上用 `--save-key world.ksd` 建立世界。每台电脑在设置里选择自己对应的 `worldN.ksd`；云端统一保存为 `world.ksd`，恢复时写回本机选择的编号，两台电脑编号不同也能交接。
- **只动世界文件**：`character*.ksd`（角色）、`global.ksd`、`user_settings.json`、其他世界，以及游戏自己的 `backup/`、`migrated/` 都不会被上传或覆盖。服务端同样只接受 `world.ksd` 一个文件。
- **设置更安全**：世界文件列表按修改时间排列，首次设置不会自动选择，避免把自己的单人世界当成共享世界；“检查文件清单”会列出将要上传/恢复的文件和保持不动的文件。
- **找到更多存档位置**：新增游戏 1.0 的本地存档目录 `Saved Games\keen games\Enshrouded\default`，并从注册表读取 Steam 安装位置（Steam 装在 D 盘等位置也能找到）。
- 抢先体验版的 8 位标识世界继续可用，行为与 1.0.0 相同。

### 升级步骤

1. **先升级服务端**：备份数据目录，停止服务，替换为 1.1.0 二进制，再启动。已有世界和备份不受影响。
2. **新建 1.0 世界**：`vault world add --id <新ID> --library friends --name <名称> --save-key world.ksd`（世界标识创建后不能修改）。
3. **再升级客户端**：每位玩家换成 1.1.0 EXE，在“设置”里选择新世界和自己的 `worldN.ksd`。设置、访问码和本地备份目录都沿用。

1.0.0 客户端连接 1.1.0 服务端时，旧的 8 位标识世界照常可用；1.0 世界需要 1.1.0 客户端。

### 请先用副本验证

Keen 官方尚未公开新存档格式。“只复制 `worldN.ksd`、不带 `global.ksd`、换一个编号也能加载”是依据服务器托管商的迁移说明做出的判断，还没有在两台 Windows 电脑上实测。第一次交接前，请先复制一份世界文件到另一台电脑，确认游戏能在世界列表里看到并正常加载，再用于正式进度。

## English

**Support for the game 1.0 save format.** Enshrouded 1.0 stores each world as one `worldN.ksd` file, and N can differ between PCs; old saves are converted automatically and the originals moved to `migrated/`. Tool 1.0.0 only understood Early Access 8-hex keys and could not manage the new saves; from 1.1.0 both formats are supported.

### Which file to download

| File | For |
| --- | --- |
| `EnshroudedSaveManager-1.1.0-win-x64.exe` | Every player (Windows 10/11 x64) — double-click, nothing to install |
| `save-server-1.1.0-linux-amd64` / `-linux-arm64` | The server admin, matching the server's architecture |
| `SHA256SUMS.txt` | Verifying downloads |

### What's new

- **Game 1.0 worlds**: create the world on the server with `--save-key world.ksd`. Each PC picks its own `worldN.ksd` in Settings; the cloud always stores `world.ksd` and restores write it back to the number chosen on that PC, so PCs with different numbers can still hand over.
- **Only the world file is touched**: `character*.ksd`, `global.ksd`, `user_settings.json`, other worlds and the game's own `backup/` and `migrated/` folders are never uploaded or overwritten. The server likewise accepts only the single `world.ksd` file.
- **Safer setup**: world files are listed by modified time and nothing is preselected on first setup, so your own solo world is never mistaken for the shared one; "Check file list" shows what will be uploaded/restored and what is left untouched.
- **More save locations found**: the game 1.0 local folder `Saved Games\keen games\Enshrouded\default`, and the Steam install path from the registry (Steam on drive D: and elsewhere).
- Early Access 8-hex worlds keep working exactly as in 1.0.0.

### Upgrading

1. **Server first**: back up the data directory, stop the service, replace the binary with 1.1.0, start it. Existing worlds and backups are unaffected.
2. **Create a 1.0 world**: `vault world add --id <new-id> --library friends --name <name> --save-key world.ksd` (a world's key cannot change later).
3. **Then clients**: every player switches to the 1.1.0 exe and picks the new world and their own `worldN.ksd` in Settings. Settings, the stored access code and local backups carry over.

A 1.0.0 client talking to a 1.1.0 server keeps working with old 8-hex worlds; game 1.0 worlds need the 1.1.0 client.

### Verify on a copy first

Keen has not published the new save format. "Copying only `worldN.ksd`, without `global.ksd`, under a different number still loads" follows server hosts' migration guides and has not yet been tested between two Windows PCs. Before the first hand-over, copy a world file to another PC and confirm the game lists and loads it, then use it for real progress.
