# 雾锁存档助手 1.0.0 / Enshrouded Save Vault 1.0.0

[中文](#中文) | [English](#english)

## 中文

第一个正式版本。Windows 客户端改为单文件，**下载后双击即用，不需要安装 .NET 或任何依赖**。

### 下载哪个文件

| 文件 | 给谁用 |
| --- | --- |
| `EnshroudedSaveManager-1.0.0-win-x64.exe` | 每位玩家（Windows 10/11 x64） |
| `save-server-1.0.0-linux-amd64` / `-linux-arm64` | 服务器管理员，按服务器架构选择 |
| `SHA256SUMS.txt` | 下载后核对文件完整性 |

EXE 目前没有代码签名，第一次运行时如果 Windows 提示“未知发布者”，选择“更多信息 → 仍要运行”。

### 新内容

- **全新界面**：浅色、深色、跟随系统三种外观；本地存档卡片按状态变色（有新进度、没有变化、检查失败、游戏运行中）；云端存档显示上传人、时间、“最新”和“本地来源”标记。
- **分步首次设置**：验证连接 → 选择世界 → 选择目录并检查文件清单 → 确认 Steam Cloud。访问码只保存在 Windows 凭据管理器。
- **更安全的上传与恢复**：
  - 检查失败时写明原因，不会被当作“没有变化”，也不能上传。
  - 确认上传后才打包，取消不会留下文件；默认名称为日期。
  - 本地有未上传的进度时，恢复按钮降为次要样式并在确认时提醒。
  - 未完成的上传可以重试、放弃或暂不处理；重试不会产生重复备份。
  - 上传和下载显示进度。
- **游戏运行时自动锁定**检查、上传和恢复，退出游戏后自动检查。
- **列表更可靠**：翻页、搜索不会悄悄改变选中的存档；在其他操作进行时输入的搜索词也不会丢失。

### 从 0.1.0 升级

直接用新 EXE 替换旧版本即可。设置、访问码和本地备份目录（`%LOCALAPPDATA%\EnshroudedSaveManager`）都沿用，不需要重新设置。服务端接口没有变化，可以继续使用 0.1.0 的服务端，或换成 1.0.0 的二进制（升级前先备份数据目录）。

### 已知限制

- 尚未在 Windows 实机上完成验收：高 DPI 显示、凭据管理器、游戏进程识别、真实存档目录和两台电脑轮流加载。请先用世界存档的副本试一遍交接。
- 界面目前只有中文。
- 服务器管理员可以读取存档，1.0 不是端到端加密。

## English

The first stable release. The Windows client is now a single file: **download and double-click — no .NET or other dependencies to install**.

### Which file to download

| File | For |
| --- | --- |
| `EnshroudedSaveManager-1.0.0-win-x64.exe` | Every player (Windows 10/11 x64) |
| `save-server-1.0.0-linux-amd64` / `-linux-arm64` | The server admin, matching the server's architecture |
| `SHA256SUMS.txt` | Verifying downloads |

The exe is not code-signed yet. If Windows warns about an "unknown publisher" on first run, choose "More info → Run anyway".

### What's new

- **New interface**: light, dark and follow-system appearance; the local-save card changes colour with its state (new progress, no changes, check failed, game running); cloud backups show uploader, time, and "Latest" / "Local source" tags.
- **Step-by-step first-run setup**: verify the connection → pick the world → choose the folder and check the file list → confirm Steam Cloud. The access code is stored only in Windows Credential Manager.
- **Safer upload and restore**:
  - A failed check shows its reason, is never treated as "no changes", and blocks uploading.
  - Packaging happens only after you confirm an upload, so cancelling leaves no files; the default name is the date.
  - While local progress is unuploaded, the restore button becomes secondary and the confirmation warns you.
  - An unfinished upload can be retried, discarded or left for later; retrying never creates a duplicate backup.
  - Upload and download show progress.
- **Game-aware**: check, upload and restore are locked while the game runs, and a check runs automatically after it exits.
- **More reliable list**: paging and searching never silently change your selection, and search input typed during another operation is never lost.

### Upgrading from 0.1.0

Replace the old exe with the new one. Settings, the stored access code and the local backup folder (`%LOCALAPPDATA%\EnshroudedSaveManager`) carry over; no new setup is needed. The server API is unchanged, so the 0.1.0 server keeps working; to switch to the 1.0.0 binary, back up the data directory first.

### Known limitations

- Not yet accepted on real Windows hardware: high-DPI display, Credential Manager, game process detection, real save folders and two PCs taking turns. Try the hand-over on a copy of your world first.
- The interface is Chinese-only for now.
- The server admin can read the saves; 1.0 is not end-to-end encrypted.
