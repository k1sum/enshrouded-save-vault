# 雾锁存档助手 1.1.1 / Enshrouded Save Vault 1.1.1

[中文](#中文) | [English](#english)

## 中文

体验改进版本，存档逻辑与 1.1.0 相同。游戏 1.0 存档支持的完整说明见 [1.1.0 版本说明](v1.1.0.md)。

### 下载哪个文件

| 文件 | 给谁用 |
| --- | --- |
| `EnshroudedSaveManager-1.1.1-win-x64.exe` | 每位玩家（Windows 10/11 x64），双击即用，无需安装 |
| `save-server-1.1.1-linux-amd64` / `-linux-arm64` | 服务器管理员，按服务器架构选择 |
| `SHA256SUMS.txt` | 下载后核对文件完整性 |

### 新内容

- **应用图标**：EXE、窗口、任务栏和 macOS 应用都使用橙色“雾”字图标，不再是空白图标；在 EXE 的“属性 → 详细信息”里能看到产品名称、说明和版本。
- **显示版本号**：窗口标题、主界面标题旁和设置底部都会显示客户端版本，方便确认用的是哪个版本。
- **说清楚为什么没有世界文件列表**：设置第 2 步会显示所选世界的格式。如果选的是抢先体验版格式（8 位标识）的世界，而存档目录里是游戏 1.0 的 `worldN.ksd`，第 3 步会直接说明原因：需要管理员把服务端升级到 1.1.0 以上，并用 `--save-key world.ksd` 新建世界。1.1.0 在这种情况下只是静默不显示列表。
- **主界面同样提示**：已保存的设置遇到同样的不匹配时，本地存档卡片会写明原因和解决办法，并暂停恢复。
- **服务器还没有世界时**，验证连接后会提示管理员建立 `world.ksd` 世界并授权。

### 升级

用新 EXE 替换旧版本即可，设置、访问码和本地备份都沿用。服务端 1.1.0 与 1.1.1 没有区别，已经升级到 1.1.0 的服务端不需要再换；还在 1.0.0 的服务端请按 [1.1.0 版本说明](v1.1.0.md) 先升级并新建 `world.ksd` 世界。

## English

A polish release; save handling is the same as 1.1.0. See the [1.1.0 release notes](v1.1.0.md) for game 1.0 save support.

### Which file to download

| File | For |
| --- | --- |
| `EnshroudedSaveManager-1.1.1-win-x64.exe` | Every player (Windows 10/11 x64) — double-click, nothing to install |
| `save-server-1.1.1-linux-amd64` / `-linux-arm64` | The server admin, matching the server's architecture |
| `SHA256SUMS.txt` | Verifying downloads |

### What's new

- **App icon**: the exe, window, taskbar and macOS app use the orange "雾" icon instead of a blank one; the exe's Properties → Details show the product name, description and version.
- **Version shown**: the window title, the header and the bottom of Settings show the client version, so you can tell which build you run.
- **Explains a missing world-file list**: step 2 of Settings shows the chosen world's format. If it is an Early Access (8-hex) world while the folder holds game 1.0 `worldN.ksd` files, step 3 says why and what to do: the admin upgrades the server to 1.1.0 or later and creates a world with `--save-key world.ksd`. 1.1.0 simply hid the list in this case.
- **Same message in the main window**: if saved settings have the same mismatch, the local-save card explains it and restore is paused.
- **No world on the server yet**: after verifying the connection, the client asks the admin to create and grant a `world.ksd` world.

### Upgrading

Replace the old exe; settings, the stored access code and local backups carry over. The 1.1.0 and 1.1.1 servers are identical, so a server already on 1.1.0 needs no change; a server still on 1.0.0 should first follow the [1.1.0 notes](v1.1.0.md) and create a `world.ksd` world.
